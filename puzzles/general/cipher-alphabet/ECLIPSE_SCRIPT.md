# Eclipse Script — Alfabeto de sustitución

> **Regla:** Mismo inglés, mismas palabras. Solo cambian las **formas** de las letras.  
> A ↔ A, B ↔ B, etc. Descifrado gradual durante el juego.

---

## Concepto visual

Letras con estética **eclipse / pergamino / estrellas**:
- Trazos curvos como arcos de eclipse
- Puntos como estrellas en algunas letras
- Serif antiguas, legibles pero extrañas
- 26 glifos únicos + opcional espacio/puntuación

## Profecía (Eclipse Script) — versión confirmada ✓

```
YOU ARE THE REASON FOR ALL OF THIS.
WHEN YOU READ THIS YOU WILL KNOW HOW MUCH I LOVE YOU.
YOU WERE NEVER ONLY THE SEEKER YOU WERE ALWAYS THE TREASURE.
```

Tono directo y romántico. Inglés básico al descifrar. Glifos **abstractos** (no parecen letras latinas).
