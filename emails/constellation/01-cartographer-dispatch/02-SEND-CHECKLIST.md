## 1. Despliegue en Cloudflare Pages 🚀

Para desplegar la carpeta `web/` completa a Cloudflare Pages de forma gratuita:

### Vía Terminal (1 comando):
```bash
npx wrangler pages deploy web --project-name=the-eclipse-order
```
*(Si te pide login la primera vez, se abrirá el navegador de Cloudflare para autorizar).*  
Te generará una URL pública tipo:
`https://the-eclipse-order.pages.dev`

### Vía Panel Web (Drag & Drop):
1. Entra en [dash.cloudflare.com](https://dash.cloudflare.com) > **Workers & Pages**.
2. Pulsa **Create application** > pestaña **Pages** > **Upload assets**.
3. Nombra el proyecto (ej. `the-eclipse-order`).
4. Arrastra la carpeta **`web`** del proyecto.
5. Pulsa **Deploy site**.

> **Nota:** `web/index.html` redirige automáticamente a la consola interactiva en `constellation/celestial-matrix/index.html`.
